📐 Tailles Disponibles

  • Small: 70px - Sites web, emails
  • Medium: 100px - En-têtes, bannières
  • Large: 130px - Présentations, print
  • XLarge: 160px - Affiches, grands formats
  • Icon: 512x512px - Apps, favicons

🎨 Variations de Couleurs

  • Fond Clair: #63003A (bordeaux)
  • Fond Sombre: #d4a5c3 (rose pâle)
  • Icône Remplie: Dégradé #63003A → #8B0052
  • Monochrome: Blanc pur
  • Points: #C89AB8 et #f0b8dc

💼 Cas d'Usage

  • Site Web: Medium/Large fond clair
  • App Mobile: Icon filled 512px
  • Email Signature: Small fond clair
  • Présentation: Large avec tagline
  • Réseaux Sociaux: Icon standard
  • Print: Large/XLarge SVG

✅ Formats Techniques

  • Format: SVG vectoriel scalable
  • Typographie: Space Grotesk Bold
  • Compatible: Web, Print, Mobile
  • Résolution: Infinie (vectoriel)
  • Poids: ~2-5 KB par fichier
  • Export PNG: Possible à n'importe quelle taille
