Comprendre les différents niveaux d'accès

Le système distingue trois rôles principaux pour la gestion des primes :

👤

Administrateur

Accès complet à toutes les fonctionnalités

  • Créer/modifier/supprimer des programmes
  • Créer des cycles de paiement
  • Gérer les attributions
  • Approuver les instances
  • Générer les fichiers de paiement
👔

Gestion opérationnelle et approbations

  • Créer/modifier des programmes
  • Créer des cycles de paiement
  • Gérer les attributions

Programmes de Primes

Configuration des règles de calcul et modèles

Les programmes (ou modèles) définissent les règles de calcul des primes. Ils servent de base pour créer des cycles de paiement récurrents ou ponctuels.

Accès aux Programmes

Navigation : Menu principal → Primes et Gratifications → Programmes

Figure 1 : Liste des programmes de primes avec filtres et statistiques

Interface de la Liste des Programmes

L'écran principal affiche :

  • 📊 Statistiques en temps réel — Total, Actifs, Inactifs
  • 🔍 Barre de recherche — Par nom, code ou description
  • 🏷️ Filtres par catégorie — Avec parts, Sans parts, Montant fixe, Calculé
  • 📋 Vue Liste ou Cartes — Changez le mode d'affichage
  • 🔄 Tri — Par date de mise à jour, nom ou code

Les 4 Catégories de Calcul

1️⃣ Primes avec Parts

Prime calculée en fonction du nombre de parts attribuées à chaque bénéficiaire.

Montant Brut = Nombre de parts × Montant de la part
Retenue IR = Montant Brut × Taux de taxe (ex: 5,28%)
Montant Net (NAP) = Montant Brut - Retenue IR

Exemple : Prime trimestrielle avec part à 50 000 FCFA. Un agent avec 3 parts reçoit 150 000 FCFA brut.

2️⃣ Primes sans Parts (Remise sur Salaire / IFT)

Deux sous-types disponibles :

  • Remise sur Salaire : Calcul basé sur le SBI (Salaire de Base Indiciaire)
Remise = SBI × 3 × Taux applicable
  • IFT (Indemnité de Fonction et de Technicité) : Montant fixe selon le rang hiérarchique, IRPP non prélevé
Grille IFT type : ├── Rang 1 (Directeur) : 500 000 FCFA ├── Rang 2 (Sous-directeur) : 400 000 FCFA ├── Rang 3 (Chef de service) : 300 000 FCFA ├── Rang 4 (Chef de bureau) : 200 000 FCFA └── Autres : 100 000 FCFA

3️⃣ Montant Fixe

Montant identique pour tous les bénéficiaires éligibles. Idéal pour les primes exceptionnelles ou uniformes.

Exemple : Prime de fin d'année de 100 000 FCFA pour tout le personnel.

4️⃣ Calcul Personnalisé

Formule mathématique personnalisée utilisant des variables dynamiques (SBI, rang, ancienneté, grade, etc.)

Périodicité Fréquence Génération Auto

Étape 1 : Informations de Base

Selon la catégorie choisie :

Définissez les critères pour déterminer qui reçoit la prime :

  • Structure ou direction
  • Grade ou catégorie

Cycles de Paiement

Gestion des instances de paiement

Un cycle représente l'application concrète d'un programme pour une période donnée.

Accès aux Cycles

Navigation : Menu principal → Primes et Gratifications → Cycles de Paiement

Figure 3 : Liste des cycles de paiement avec filtres et statuts

Statuts des Cycles

Statut Description Actions Possibles
🟡 Brouillon En cours de préparation Modifier, Supprimer
🔵 En Attente Calcul programmé Annuler
🟢 Généré Calculs terminés Réviser, Approuver, Gérer
🟠 Sous Révision En cours de vérification Ajuster, Approuver
✅ Approuvé Validé pour paiement Générer Paiements
💰 Payé Fichiers générés Exporter uniquement
🔴 Annulé Abandonné Supprimer

Créer un Cycle

  1. Lancer la création — Cliquez sur « + Nouveau Cycle »
  2. Sélectionner le programme — Choisissez le programme de primes
  3. Période de référence — Saisissez la période (ex: "2025-Q1")
  4. Options de génération — Automatique ou manuel
  5. Créer — Le cycle est créé avec le statut approprié

Cycle de Vie Détaillé

Phase 1 : Génération

Le système récupère l'instantané du personnel, applique les règles d'éligibilité, calcule les montants et crée les attributions individuelles.

Temps estimé : 30 secondes à 2 minutes selon le volume

Phase 2 : Révision

  • Visualiser la liste complète
  • Vérifier les montants calculés
  • Comparer avec les historiques
  • Identifier les anomalies

Phase 3 : Ajustements

Deux méthodes disponibles :

  • Assistant de Gestion (Recommandé) — Interface guidée
  • Ajustements Directs — Modification rapide

Phase 4 : Approbation

⛔
Attention

L'approbation fige les montants. Les modifications ultérieures nécessiteront une justification.

Phase 5 : Génération des Paiements

Fichiers générés :

  • 📊 Excel — Liste détaillée pour la trésorerie
  • 📄 PDF — Document officiel

Gestion des Attributions

Assistant de gestion (Wizard) et ajustements individuels

L'Assistant de Gestion (Wizard) est l'interface principale pour gérer les allocations d'un cycle de paiement. Il guide l'utilisateur à travers 4 étapes pour réviser, ajuster, exporter et finaliser les attributions.

Étape 1 : Ajuster les Allocations

Revoyez et modifiez les attributions de primes pour chaque bénéficiaire :

  • ✏️ Modifier — Ajustez le nombre de parts ou le montant final
  • ❌ Exclure — Retirez un bénéficiaire avec motif obligatoire
  • ✅ Inclure — Réintégrez un bénéficiaire précédemment exclu
  • 📜 Historique — Consultez les modifications passées

Étape 2 : Confirmer les Allocations

Vérifiez les données historiques et validez les calculs :

  • Comparez avec les cycles précédents
  • Identifiez les anomalies ou écarts
  • Validez les montants finaux

Étape 3 : Exporter les Données

Générez les documents pour traitement :

  • 📊 Export Excel — Liste détaillée pour la trésorerie/paie
  • 📄 Export PDF — Document officiel pour archivage et signatures
  • 📜 Historique des exports — Liste de tous les fichiers générés

Étape 4 : Terminé

L'instance est prête pour approbation. Actions disponibles :

  • ✅ Approuver l'instance
  • 📥 Exporter les données finales
  • ↩️ Retourner à la liste des cycles

Lorsque vous modifiez le montant de la part ou le taux de taxe, le système recalcule automatiquement toutes les allocations. Une animation de chargement s'affiche pendant le traitement.

Filtres et Recherche

  • 📊 Statut — Tous, Éligibles, Exclus, Ajustés

  • 🏛️ Sous-structure — Filtrer par sous-direction

Pagination

Pour les grandes listes, utilisez la pagination :

  • Affichage : 25, 50 ou 100 lignes par page
  • Navigation : Page précédente / suivante
  • Indicateur : "Affichage 1-25 sur 250"

Fenêtre d'Ajustement

En cliquant sur "Modifier" pour une allocation :

  1. Informations employé — Photo, nom, matricule, statut actuel
  2. Montant original — Calculé automatiquement
  3. Nombre de parts — Modifiable si prime avec parts
  4. Montant final — Peut être saisi manuellement
  5. Résumé de l'ajustement — Affiche la différence (+ ou -)
  6. Raison — Obligatoire pour justifier le changement
📜
Traçabilité

Toutes les modifications sont enregistrées avec la date, l'utilisateur et le motif. L'historique complet est visible dans la fenêtre d'ajustement.

Rapports et Exports

Génération de rapports récapitulatifs et exports

Le module de rapports permet de générer des synthèses consolidées des primes versées, filtrées par période, catégorie et personnel.

Accès aux Rapports

Navigation : Menu principal → Primes et Gratifications → Rapports

Figure 5 : Page des rapports et exports avec filtres

Filtres Disponibles

Filtre Options Description
Catégorie Toutes, Avec parts, Sans parts Type de calcul de prime
Statut Tous, Approuvé, Payé État du cycle
Période Date début / Date fin Plage de dates pour le rapport
Personnel Recherche par nom Générer un rapport individuel

Structure du Rapport

Le rapport est organisé en sections selon le type de prime :

📊 Section : Primes avec Parts

Affiche toutes les primes calculées sur base de parts :

Colonne Description
Programme Nom du modèle de prime
Période Référence du cycle (ex: 2026-Q1)
Total Parts Somme des parts attribuées
Montant Brut Total avant retenues
Retenue IR Total des impôts retenus
Montant Net Total à payer (NAP)

📋 Section : Primes sans Parts

Affiche les primes de type Remise ou IFT :

Colonne Description
Programme Nom du modèle de prime
Type Remise sur salaire ou IFT
Période Référence du cycle
Montant Brut Total avant retenues
Retenue IR prélevé (0 pour IFT)
Montant Net Total à payer

📈 Totaux Généraux

En bas du rapport, un récapitulatif global :

  • Total Brut Global — Somme de tous les montants bruts
  • Total Retenues — Somme de tous les impôts
  • Total Net Global — Somme de tous les NAP

Impression

Cliquez sur le bouton 🖨️ Imprimer en haut de la page pour générer une version imprimable du rapport. Le format est optimisé pour l'impression avec :

  • En-tête avec logo et date
  • Tableaux formatés
  • Totaux mis en évidence
  • Zone pour signatures

Types d'Exports depuis les Cycles

📊 Export Excel — Liste Détaillée

Usage : Traitement trésorerie, analyse, intégration paie

Colonnes incluses :

  • Matricule et nom complet
  • Structure (Direction/Sous-direction)
  • Nombre de parts (si applicable)
  • Montant brut, retenue IR, montant net
  • Statut de l'allocation

📄 Export PDF — Document Officiel

Usage : Archivage légal, validation hiérarchique

Sections du document :

  • Page de garde avec informations du cycle
  • Liste nominative des bénéficiaires
  • Récapitulatif par structure
  • Totaux et zone de signatures
📥
Historique des Exports

Tous les fichiers générés sont conservés et accessibles depuis l'étape "Exporter Données" du Wizard. Vous pouvez télécharger à nouveau un export précédent sans le régénérer.

Rapport Individuel par Personnel

Pour générer un rapport pour un agent spécifique :

  1. Utilisez le filtre "Personnel" et saisissez le nom
  2. Sélectionnez l'agent dans la liste
  3. Le rapport affiche uniquement ses primes
  4. Imprimez pour archivage individuel

FAQ et Dépannage

Questions fréquentes et solutions

Questions Fréquentes

? Un personnel éligible n'apparaît pas dans le cycle

Solution :

  • Vérifiez les règles du programme
  • Contrôlez la fiche personnel
  • Ajoutez manuellement si exception validée
? Le calcul du montant ne correspond pas

Vérifications :

  • Type de calcul du programme
  • Valeur de la part
  • Paramètres du personnel
  • Taux de taxe
? Je ne peux pas approuver un cycle

Causes : Rôle insuffisant (Opérateur ne peut pas) ou statut incorrect

Solution : Demandez à un Gestionnaire ou vérifiez le statut

? L'export ne fonctionne pas

Solution :

  • Réessayez
  • Exportez par structure si volume important
  • Contactez l'administrateur

Messages d'Erreur Courants

Message Signification Action
Not authorized Permissions insuffisantes Vérifiez votre rôle
Failed to load instance Cycle introuvable Retournez à la liste
Instance not found ID invalide Vérifiez l'URL

Bonnes Pratiques

✅
À FAIRE
  • Testez sur un échantillon d'abord
  • Vérifiez les totaux avant approbation
  • Documentez les ajustements
  • Exportez pour archivage
❌
À ÉVITER
  • Approuver sans révision
  • Modifier sans justification
  • Supprimer les cycles approuvés
  • Oublier d'exporter
