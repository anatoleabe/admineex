Rôles et Permissions

Comprendre les différents niveaux d'accès

Le système distingue trois rôles principaux pour la gestion des primes :

👤

Administrateur

Accès complet à toutes les fonctionnalités

  • Créer/modifier/supprimer des programmes
  • Créer des cycles de paiement
  • Gérer les attributions
  • Approuver les instances
  • Générer les fichiers de paiement
👔

Gestionnaire de Primes

Gestion opérationnelle et approbations

  • Créer/modifier des programmes
  • Créer des cycles de paiement
  • Gérer les attributions
  • Approuver les instances
  • Générer les fichiers de paiement
✏️

Opérateur de Primes

Création et ajustements uniquement

  • Créer des cycles de paiement
  • Ajuster les attributions
  • Exporter les rapports
  • Ne peut PAS approuver
  • Ne peut PAS générer les paiements
⚠️
Important

Seuls les Administrateurs et Gestionnaires peuvent approuver les instances et générer les fichiers de paiement.

3

Programmes de Primes

Configuration des règles de calcul

Les programmes définissent les règles de calcul des primes.

Accès aux Programmes

Navigation : Menu principal → Primes et Gratifications → Programmes

Types de Programmes

1️⃣ IFT (IRPP non prélevé)

Prime basée sur le rang hiérarchique, sans prélèvement d'impôt.

Rang 1 (Directeur) : 500 000 FCFA Rang 2 (Sous-directeur) : 400 000 FCFA Rang 3 (Chef de service) : 300 000 FCFA

2️⃣ Primes avec Parts

Prime calculée en fonction du nombre de parts attribuées.

Montant Brut = Nombre de parts × Montant de la part
Retenue IR = Montant Brut × Taux de taxe
Montant Net = Montant Brut - Retenue IR

3️⃣ Montant Fixe

Montant identique pour tous les bénéficiaires éligibles.

4️⃣ Calcul Personnalisé

Formule mathématique personnalisée utilisant des variables (SBI, rang, ancienneté, etc.)

Créer un Programme

  1. Accéder à la création — Cliquez sur « + Nouveau Programme »
  2. Informations de base — Nom descriptif, Code unique, Périodicité
  3. Type de calcul — Sélectionnez le type approprié
  4. Règles d'éligibilité — Définissez les critères
  5. Configuration fiscale — Taux de taxe si applicable
  6. Enregistrer — Validez la création
💡
Conseil

Testez toujours vos règles d'éligibilité avec des cas réels avant de lancer un cycle complet.

4

Cycles de Paiement

Gestion des instances de paiement

Un cycle représente l'application concrète d'un programme pour une période donnée.

Accès aux Cycles

Navigation : Menu principal → Primes et Gratifications → Cycles de Paiement

Statuts des Cycles

Statut Description Actions Possibles
🟡 Brouillon En cours de préparation Modifier, Supprimer
🔵 En Attente Calcul programmé Annuler
🟢 Généré Calculs terminés Réviser, Approuver, Gérer
🟠 Sous Révision En cours de vérification Ajuster, Approuver
✅ Approuvé Validé pour paiement Générer Paiements
💰 Payé Fichiers générés Exporter uniquement
🔴 Annulé Abandonné Supprimer

Créer un Cycle

  1. Lancer la création — Cliquez sur « + Nouveau Cycle »
  2. Sélectionner le programme — Choisissez le programme de primes
  3. Période de référence — Saisissez la période (ex: "2025-Q1")
  4. Options de génération — Automatique ou manuel
  5. Créer — Le cycle est créé avec le statut approprié

Cycle de Vie Détaillé

Phase 1 : Génération

Le système récupère l'instantané du personnel, applique les règles d'éligibilité, calcule les montants et crée les attributions individuelles.

Temps estimé : 30 secondes à 2 minutes selon le volume

Phase 2 : Révision

  • Visualiser la liste complète
  • Vérifier les montants calculés
  • Comparer avec les historiques
  • Identifier les anomalies

Phase 3 : Ajustements

Deux méthodes disponibles :

  • Assistant de Gestion (Recommandé) — Interface guidée
  • Ajustements Directs — Modification rapide

Phase 4 : Approbation

⛔
Attention

L'approbation fige les montants. Les modifications ultérieures nécessiteront une justification.

Phase 5 : Génération des Paiements

Fichiers générés :

  • 📊 Excel — Liste détaillée pour la trésorerie
  • 📄 PDF — Document officiel

Ajuster une Attribution

Méthode 1 : Modification Rapide

  1. Cliquez sur l'icône ✏️
  2. Modifiez les valeurs
  3. Enregistrez

Méthode 2 : Assistant de Gestion

  1. Accédez au cycle
  2. Cliquez sur « Gérer dans l'Assistant »
  3. Suivez les étapes guidées

Exclure un Bénéficiaire

  1. Trouvez le personnel concerné
  2. Cliquez sur « Exclure »
  3. Saisissez le motif (obligatoire)
  4. Confirmez

Approuver un Cycle

Prérequis :

  • Rôle : Gestionnaire ou Administrateur
  • Statut : « Généré » ou « Sous Révision »

Étapes :

  1. Accéder aux détails du cycle
  2. Vérifier : nombre de bénéficiaires, montant total, répartition
  3. Lancer l'approbation
  4. Confirmation
  5. Instance approuvée

Annuler un Cycle

  1. Accédez au cycle
  2. Cliquez sur « Annuler l'Instance »
  3. Saisissez le motif
  4. Confirmez

FAQ et Dépannage

Questions fréquentes et solutions

Questions Fréquentes

? Un personnel éligible n'apparaît pas dans le cycle

Solution :

  • Vérifiez les règles du programme
  • Contrôlez la fiche personnel
  • Ajoutez manuellement si exception validée
? Le calcul du montant ne correspond pas

Vérifications :

  • Type de calcul du programme
  • Valeur de la part
  • Paramètres du personnel
  • Taux de taxe
? Je ne peux pas approuver un cycle

Causes : Rôle insuffisant (Opérateur ne peut pas) ou statut incorrect

Solution : Demandez à un Gestionnaire ou vérifiez le statut

? L'export ne fonctionne pas

Solution :

  • Réessayez
  • Exportez par structure si volume important
  • Contactez l'administrateur

Messages d'Erreur Courants

Message Signification Action
Not authorized Permissions insuffisantes Vérifiez votre rôle
Failed to load instance Cycle introuvable Retournez à la liste
Instance not found ID invalide Vérifiez l'URL

Bonnes Pratiques

✅
À FAIRE
  • Testez sur un échantillon d'abord
  • Vérifiez les totaux avant approbation
  • Documentez les ajustements
  • Exportez pour archivage
❌
À ÉVITER
  • Approuver sans révision
  • Modifier sans justification
  • Supprimer les cycles approuvés
  • Oublier d'exporter
