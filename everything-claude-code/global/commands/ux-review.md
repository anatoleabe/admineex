# Command: /ux-review <scope>

Goal:
Assess usability and clarity without changing business behavior.

Focus:
- Readability for non-technical users
- Label clarity and wording consistency
- Create/View/List/Dashboard coherence
- Long text overflow, truncation, and visibility issues
- Ambiguous financial terms and risky UI copy

Rules:
- Do not change backend logic.
- Keep recommendations incremental and safe.
- Prefer display-only fixes first.

Steps:
1. Identify screens/components in <scope>.
2. Evaluate information architecture and section hierarchy.
3. Flag unclear technical wording and mixed-language copy.
4. Flag truncation/overflow/readability issues.
5. Propose prioritized UI-only fixes.

Output format:
Use global/templates/output-format.md
